# dex.moe

Source for [dex.moe](https://dex.moe), the personal site of Dex Hunter. Static HTML served by GitHub Pages (custom domain in `CNAME`).

- `index.html`: the homepage.
- `cv.html`: the CV, hand-written HTML with its styles embedded in the page.
- `assets/`, `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`: images and icons.

The LaTeX version of the CV is in [yaacv](https://github.com/dexhunter/yaacv). Update both when the CV changes.
